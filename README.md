# Onix Engineering Solutions

# PROYECTO

Diseñar y desarrollar un sitio web premium para Refrigeraciones Onix, una empresa especializada en ingeniería termomecánica, climatización, ventilación y soluciones HVAC para proyectos comerciales, industriales y corporativos.

El objetivo principal del sitio es transmitir confianza, capacidad técnica y profesionalismo desde el primer segundo, posicionando a la empresa como un socio estratégico de ingeniería y no como un simple instalador de equipos de aire acondicionado.

Todo el diseño debe comunicar planificación, ingeniería, organización y experiencia.

---

# OBJETIVOS DEL SITIO

El sitio debe funcionar como una herramienta comercial de alto nivel capaz de:

- Generar confianza inmediata.

- Comunicar experiencia técnica.

- Explicar claramente el valor diferencial de la empresa.

- Posicionar a Refrigeraciones Onix como especialista en proyectos HVAC.

- Atraer proyectos de mayor valor.

- Filtrar clientes que buscan únicamente precio.

- Mostrar una metodología profesional.

- Convertir visitas en consultas calificadas.

---
